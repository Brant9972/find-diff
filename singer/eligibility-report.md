# 台灣玩家題庫資格審閱

更新：2026-10-21

現行歌手339題、演員329題，68人跨類別共用ID，混合去重600位，共668筆模式作品提示。

原600位逐人編輯審閱後保留506、停用94；本批新增9位歌手及85位演員，補回600位。原先停用的94位（包含龔子棋）沒有恢復。本報告共694個人物審閱紀錄；王心如為王樂妍舊名，不另計一人。

## 方法與限制

在台灣有演藝／音樂發展經歷，或有台灣觀眾熟悉的代表作與討論依據。國籍、團體連帶知名度及單篇提及不足以自動入選。

逐人編輯審閱既有簡介與代表作品，對邊界人物補查台灣來源；不是600人的獨立量化聲量調查。依據不足先停用，不代表斷言從未來台。 b005新增94人的人物簡介與代表作品編輯審閱；以現有來源及針對性補查核對台灣發展，作品文字比對僅供一致性檢查。

本次新增94張照片完成目視檢查；不合適的照片／候選已替換。作品文字自動比對僅是一致性檢查，不能取代演出名單查證。保留部分歷史照片及輕微角度；沒有宣稱所有人物均做全新獨立聲量調查。代表作品可能來自台灣以外地區，收錄資格依人物整體台灣發展或台灣熟悉度判斷。
