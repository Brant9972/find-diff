# 猜名人 800 位題庫擴充（獨立工作區）

目標：在正式 **600 位不同人物**的基礎上 **淨新增 200 位**（最終 800），不是將另一對話已計畫的 55 人汰換算入 200。

## 誰編輯什麼

- **本題庫對話（800 人擴充）**：只在 `roster-expansion-800-20261022` 分支更新 `singer/expansion-800/*`。
- **另一演員汰換對話**：繼續原 55 人替換、照片與來源審查，使用既有 actor/photo 工作分支。
- **遊戲工程對話**：負責 `singer/game.js` 的模式與功能；未完成綜藝模式前，綜藝人物不加入正式題庫。
- **照片專員**：可從本分支讀候選人物，但照片素材應放自己專屬分支，勿改本題庫檔案。

## 防衝突原則

1. **不共編** `questions.json`、`actors.json`、`hints.json`、`eligibility-review.json`、`game.js` 或既有 `photos/`。
2. 不把舊分支的整份 JSON 蓋回 `main`；僅將通過審核的個別人物合併到**最新** main。
3. 不重複登錄同名、別名、同時會唱歌/演戲/主持的人；一人只算一個 unique ID。
4. 缺照片、五官裁切、授權或提示者，**只列候選，不計入可玩人數**。
5. 每次上線前由整合人員驗證：現有可玩 unique + 本批新 unique、每題照片與各模式提示存在、全題庫 JSON 正常。

## 進度與原始資料

- [plan.json](plan.json)：完整規範及每批里程碑。
- [b001-candidates.json](b001-candidates.json)：候選人物池，**不是已完成或已上線的可玩題目**。

人物資格、照片版權、代表作品仍需逐一驗證；此資料夾絕不可直接作為遊戲 `fetch` 讀取的正式題庫。
